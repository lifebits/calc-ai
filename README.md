# calc-ai

Калькулятор в командной строке — тестовый проект для MDP: код, тесты, CI на GitHub Actions
и задачи, записанные реестром в git.

```bash
npm install
npm test
npm run build
npm run calc -- "2,5 * 4"
```

Фича и её задачи — [docs/calculator/PLAN.md](docs/calculator/PLAN.md) и
[docs/calculator/CLC-TASKS.md](docs/calculator/CLC-TASKS.md). Статус задачи — значок в заголовке
её записи; MDP переносит записи в свой трекер импортом из репозитория.

Задачи проекта на трекере MDP закрываются сами, когда все их PR слиты, — после ближайшей синхронизации.
