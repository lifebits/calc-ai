# CLC-TASKS.md — задачи калькулятора

> Реестр задач фичи [«Калькулятор»](PLAN.md). Статус — значок в заголовке записи:
> ⬜ не начата · 🟡 в работе · 🔵 на ревью · ✅ готова · ⛔ заблокирована.
> Одна задача — одна ветка — один PR.

## Волна 1 — арифметика

### CLC-T01 — Сложение и вычитание ✅

Две операции над целыми и дробными числами: `calc "2 + 3"` печатает `5`.

- **Размер:** S
- **Тип:** Задача
- **Приоритет:** Высокий
- **Оценка:** 4h

### CLC-T02 — Умножение и деление 🔵

Деление на ноль показывает ошибку «деление на ноль», а не бесконечность.

- **Размер:** S
- **Тип:** Задача
- **Приоритет:** Высокий
- **Оценка:** 4h

### CLC-T03 — Дробная часть через запятую 🟡

`calc "2,5 * 4"` — `10`: запятая читается как точка, в ответе — как ввёл пользователь.

- **Размер:** XS
- **Тип:** Задача
- **Оценка:** 2h

## Волна 2 — удобство

### CLC-T04 — История вычислений ⬜

Последние десять выражений с результатами сохраняются между запусками; `calc --history`
их печатает.

- **Размер:** M
- **Тип:** Задача
- **Приоритет:** Обычный
- **Оценка:** 1d

### CLC-T05 — Скобки и порядок действий ⛔

Выражения из нескольких операций со скобками: `calc "2 * (3 + 4)"` — `14`. Ждёт CLC-T02:
разбор выражения строится поверх готовых операций.

- **Размер:** M
- **Тип:** Задача
- **Оценка:** 2d

### CLC-T06 — Число с пробелами между разрядами не читается 🟡

`calc "1 000 + 1"` отвечает «не понимаю выражение»: пробел внутри числа рвёт разбор.
Пробелы между разрядами нужно убирать до разбора.

- **Размер:** XS
- **Тип:** Баг
- **Приоритет:** Высокий
- **Оценка:** 1h

### CLC-T07 — Тёмная тема — снята

Не нужна: у калькулятора нет графического интерфейса.
