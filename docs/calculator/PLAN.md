# Калькулятор

Калькулятор в командной строке: пользователь пишет выражение, программа печатает результат
или понятную ошибку.

## Зачем

Тестовый проект для MDP: на нём проверяется импорт задач из репозитория, синхронизация
коммитов и PR, пайплайны GitHub Actions и прогоны агента.

## Что входит

- арифметика над двумя числами: сложение, вычитание, умножение, деление;
- целые и дробные числа, дробная часть через точку или запятую;
- понятные ошибки: деление на ноль, нечисловой ввод, непонятное выражение;
- дальше — история вычислений и выражения со скобками.

## Чего не входит

- графический интерфейс;
- функции (корень, степень, тригонометрия).

## Как проверяем

Каждая задача закрывается тестами в `test/`; CI гоняет проверку типов, тесты и сборку на
каждый PR и на `main`.
